# 03 — Literature Matrix (Agentic Pilot, IEEE conference paper)

Compiled by the Literature Scout sub-agent, 2026-09-30. BibTeX: `paper/references.bib` (35 entries, keys match this table).

## How entries were verified

- **Network limits:** From this sandbox, direct page fetches to arxiv.org, doi.org, aclanthology.org, openreview.net, proceedings.neurips.cc, iclr.cc, openaccess.thecvf.com, proceedings.mlr.press, usenix.org, dblp.org, crossref and semanticscholar were **blocked by the egress proxy**. Two channels were available:
  1. **WebSearch** over the web index. It returned the primary-source landing pages (arXiv abs, ACL Anthology, NeurIPS/ICML/MLSys proceedings, CVF open access, ACM DL, Springer, USENIX), along with their indexed metadata (title, authors, venue, pages, DOI).
  2. **WebFetch on github.com**, which reached the authors' official repositories and read their own BibTeX blocks verbatim.
- **What "verification URL" means below:** it is the primary-source page whose indexed metadata confirmed the entry. Where a GitHub README was actually fetched, that URL is listed too, marked "(repo BibTeX fetched)".
- **Rule for inclusion:** every entry has title, first 3+ authors and venue/year confirmed by at least one primary-source listing. Pages and DOIs appear only where a source stated them.
- **Recommendation:** before camera-ready, spot-check the DOIs in a normal browser. This covers roughly 10 entries.

## Related-work comparison table (only from what each paper reports)

**Legend:**
- **yes:** the paper reports this capability.
- **partial:** the paper reports a weaker or related form.
- **no:** the paper reports the opposite, for example only closed API models.
- **n.r.:** not reported.

**Column meanings:**
- **Local/open models:** the paper runs the agent on open or locally hostable models.
- **Web / Desktop:** the target environment.
- **Verif. gate:** task completion is gated on an explicit check of the environment, inside the agent at runtime.
- **Persists evidence:** the system stores screenshots or state artifacts as a record.
- **Memory:** cross-step or cross-episode memory.
- **Injection defense:** the paper proposes or evaluates a prompt-injection defense.
- **Human approval:** risky actions require user confirmation.
