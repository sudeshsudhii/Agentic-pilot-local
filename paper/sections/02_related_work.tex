\section{Related Work}
\label{sec:related}

\subsection{Reasoning-and-acting agents}
ReAct interleaves free-text reasoning with tool actions and observations~\cite{yao2023react}, building on chain-of-thought prompting~\cite{wei2022chain}. Toolformer shows that a model can learn when to call an external API~\cite{schick2023toolformer}. Reflexion stores verbal self-critiques in an episodic buffer and retries with them~\cite{shinn2023reflexion}; RCI applies recursive self-criticism to computer tasks~\cite{kim2023rci}; Voyager accumulates a skill library and uses a model-based self-check before committing a skill~\cite{wang2024voyager}. In all of these, the decision that a task is finished is made by the model, sometimes with a critic that is also a model. Huang et al.\ find that such intrinsic self-correction does not reliably improve reasoning without external feedback~\cite{huang2024cannot}. Agentic Pilot moves the completion decision out of the model and into a check on the observed page.

\subsection{Web agents and benchmarks}
Early web agents were trained with reinforcement or imitation learning on MiniWoB-style pages~\cite{shi2017wob}. Mind2Web pairs a small ranking model that filters DOM candidates with an LLM that chooses the action~\cite{deng2023mind2web}, and WebArena evaluates agents on self-hosted sites with functional correctness checks~\cite{zhou2024webarena}. WebVoyager drives live sites from screenshots and uses a multimodal model to judge saved trajectories after the episode~\cite{he2024webvoyager}. The correctness checks in these works belong to the benchmark and run after the episode ends. Our gate runs inside the agent at the moment it tries to stop.

\subsection{Desktop, OS and mobile GUI agents}
OSWorld provides execution-based checkers for tasks in real operating systems and reports a large gap between agents and people~\cite{xie2024osworld}. UFO controls Windows applications through UI Automation and asks the user to confirm sensitive actions~\cite{zhang2025ufo}. AppAgent learns reusable documentation of smartphone apps~\cite{zhang2025appagent}, and GPTDroid and QTypist apply LLMs to mobile GUI testing and text-input generation~\cite{liu2024gptdroid,liu2023qtypist}. These systems either rely on hosted models or target testing rather than verified completion of user tasks. Our desktop extension (Section~\ref{sec:desktop}) borrows UFO's accessibility-first control and OSWorld's state-based checking, but places the checks inside the agent loop.

\subsection{Visual grounding for GUI interaction}
SeeAct finds that grounding a chosen action onto the right element is the main bottleneck for multimodal web agents, and that combining HTML with the image outperforms Set-of-Mark overlays~\cite{zheng2024seeact,yang2023som}. CogAgent and SeeClick train vision-language models that locate elements from screenshots alone~\cite{hong2024cogagent,cheng2024seeclick}, and OmniParser converts screenshots into structured element lists~\cite{lu2024omniparser}. These results motivate our ordering: structured DOM grounding first, pixel-level grounding only when the DOM route fails.

\subsection{Agent memory and retrieval}
Retrieval-augmented generation couples a model with a non-parametric store~\cite{lewis2020rag}, usually indexed with sentence embeddings~\cite{reimers2019sbert}. Generative Agents score memories by recency, importance and relevance~\cite{park2023generative}, and MemGPT pages context between tiers in the manner of an operating system~\cite{packer2023memgpt}. None of these ties a stored memory to verified evidence of the outcome it describes, which is what an execution agent needs if it is to learn from its own runs.

\subsection{Security of LLM agents}
Indirect prompt injection places instructions in content the agent reads, such as a web page~\cite{greshake2023indirect}. Liu et al.\ formalize such attacks and benchmark defenses~\cite{liu2024formalizing}; InjecAgent and AgentDojo measure how often tool-using agents follow injected instructions~\cite{zhan2024injecagent,debenedetti2024agentdojo}. A browser agent reads untrusted text at every step, so it needs both input filtering and a policy that keeps high-impact actions under human control.

\subsection{Local and on-device inference}
Open-weight families such as Qwen2.5 and Qwen2-VL provide text and vision models at sizes that run on consumer hardware~\cite{yang2024qwen25,wang2024qwen2vl}, and weight quantization further reduces their memory footprint~\cite{lin2024awq}. Surveys of LLM agents~\cite{wang2024survey,xi2025rise} note that dependable execution and deployment constraints remain open problems. Whether small local models can complete verified GUI tasks is largely unmeasured; our evaluation protocol is designed to measure it.
