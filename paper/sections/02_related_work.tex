\section{Related Work}
\label{sec:related}

\paragraph{Reasoning-and-acting agents} ReAct interleaves reasoning with tool actions~\cite{yao2023react}, building on chain-of-thought prompting~\cite{wei2022chain}; Toolformer learns when to call an API~\cite{schick2023toolformer}. Reflexion and RCI let the model critique and retry its own attempts~\cite{shinn2023reflexion,kim2023rci}, and Voyager accumulates skills checked by a model~\cite{wang2024voyager}. In all of these the decision that a task is finished is made by a model, and intrinsic self-correction without external feedback does not reliably help~\cite{huang2024cannot}.

\paragraph{Web agents} Early web agents learned on MiniWoB-style pages~\cite{shi2017wob}. Mind2Web pairs a small ranker over candidate elements of the page's Document Object Model (DOM) with an LLM that chooses the action~\cite{deng2023mind2web}; WebArena evaluates on self-hosted sites with functional checks~\cite{zhou2024webarena}; WebVoyager drives live sites from screenshots~\cite{he2024webvoyager}; and SeeAct finds grounding, not planning, to be the bottleneck, with HTML plus image outperforming Set-of-Mark overlays~\cite{zheng2024seeact,yang2023som}.

\paragraph{Computer-use and GUI agents} OSWorld and Windows Agent Arena run agents in real operating systems with execution-based checkers~\cite{xie2024osworld,bonatti2024waa}. UFO controls Windows applications through UI Automation and asks the user to confirm sensitive actions~\cite{zhang2025ufo}; Agent S adds experience-augmented hierarchical planning and an agent--computer interface~\cite{agashe2025agents}; AppAgent learns reusable app documentation on smartphones~\cite{zhang2025appagent}, and LLMs also drive mobile GUI testing~\cite{liu2024gptdroid,liu2023qtypist}. CogAgent, SeeClick and UI-TARS ground actions from screenshots with open models~\cite{hong2024cogagent,cheng2024seeclick,qin2025uitars}, and OmniParser turns screenshots into element lists~\cite{lu2024omniparser}. These works establish capable perception and planning for desktop interaction; they say less about when the agent itself may conclude that a task is done.

\paragraph{Completion checking} The checkers of WebArena, OSWorld and Windows Agent Arena belong to the benchmark and run after the episode. WebVoyager uses a multimodal model to judge saved trajectories~\cite{he2024webvoyager}, Pan et al.\ use model-based evaluators to judge and refine web and device agents~\cite{pan2024autonomous}, and Sumyk and Kosovan train a vision-language judge of task completion for macOS applications~\cite{sumyk2025done}. Agentic Pilot instead places explicit, environment-grounded predicates inside the agent loop, records their inputs as evidence, and measures their false completions and false rejections; a model-based judge is complementary and could serve as a second opinion.

\paragraph{Memory} Retrieval-augmented generation couples a model with a non-parametric store~\cite{lewis2020rag} indexed by sentence embeddings~\cite{reimers2019sbert}; Generative Agents and MemGPT manage memory by relevance or paging~\cite{park2023generative,packer2023memgpt}. None ties a stored memory to verified evidence of its outcome.

\paragraph{Security of agents} Indirect prompt injection hides instructions in content the agent reads~\cite{greshake2023indirect}; existing defenses are insufficient in systematic evaluations~\cite{liu2024formalizing}, and InjecAgent and AgentDojo measure how often tool-using agents comply~\cite{zhan2024injecagent,debenedetti2024agentdojo}. ToolEmu exposes high-stakes failures of tool agents in an emulated sandbox~\cite{ruan2024toolemu}, OS-Harm measures misuse, injection and misbehavior of computer-use agents~\cite{kuntz2025osharm}, and CaMeL separates trusted control flow from untrusted data by design~\cite{debenedetti2025camel}. For a local agent, these results argue for deterministic action policies and human approval rather than input filtering alone.

\paragraph{Local inference} Open-weight families such as Qwen2.5 and Qwen2-VL run on consumer hardware~\cite{yang2024qwen25,wang2024qwen2vl}, helped by quantization~\cite{lin2024awq}; surveys list trustworthiness among the open problems of LLM agents~\cite{wang2024survey,xi2025rise}.
