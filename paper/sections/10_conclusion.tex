\section{Conclusion}
\label{sec:conclusion}

Agentic Pilot runs a browser agent against local models and reports success only when a check on the observed page passes. Separating observation, planning, execution, verification and recovery into graph nodes made it possible to state that rule formally and test it in isolation: on constructed end states it withholds most premature completions a dispatch-only agent would report, but inside the live node the planner's reasoning and dispatch-based step status weaken it, and each miss points to a missing check. The same structure extends to files, processes and applications once accessibility trees, typed postconditions and deterministic permission tiers replace the DOM, page checks and model-assigned risk. What remains is to close those gaps, remove case-specific code, activate the designed recovery and memory paths, and measure the full system on real tasks.
