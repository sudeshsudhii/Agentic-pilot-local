\begin{abstract}
Language-model agents that operate a browser can report a task as finished when it is not, and many send every observation to a hosted model. Agentic Pilot is an open-source browser agent whose models run locally through Ollama and which may report completion only when a rule-based predicate over the observed page holds; the inputs of each decision are stored as evidence. We formalize this evidence-gated completion, separating action dispatch from task completion, and measure it with false completion and false rejection rates. In a component study inside the agent's live verification node, the gate withheld completion in 20 of 23 unsatisfied design states (Wilson 95\% interval 0.68--0.95) that a dispatch-only rule accepts, and rejected 1 of 15 satisfied ones. On 42 held-out states frozen before testing it withheld 9 of 22 (0.23--0.61; exact McNemar $p=0.004$) and none of the 5 unsatisfied extraction states, because its answer check is triggered by request wording and accepts any answer that repeats a goal term. Removing any single conjunct changed at most three held-out decisions. A decision costs a median of 27\,ms and no model call. We enforce that model traffic stays on the machine; in 70 agent episodes the agent process opened no non-loopback connection. We release an end-to-end harness with self-hosted sites, 40 tasks, an independent oracle that agreed with all 114 scripted trajectories, and baselines; no end-to-end run with a language model is reported.
\end{abstract}
