\begin{abstract}
LLM-based assistants that operate software for a user often send screenshots and page content to hosted models, often keep no memory across sessions, and can declare a task finished when it is not. We present Agentic Pilot, an open-source agent that runs its language and vision models locally through Ollama and drives Chromium through Playwright. The agent is a LangGraph state machine with separate observation, planning, execution, verification and recovery nodes, and it may report a task complete only when a completion predicate evaluated on the live page holds; evaluations are logged next to per-action before/after screenshots. Grounding uses Document Object Model (DOM) elements first and a local vision model as fallback; calls are routed to small models by role, CAPTCHAs halt the task, and high-risk intents need approval. We formalize the gate and define a false completion rate. On 38 constructed browser end states, the original gate withheld completion in 13 to 15 of the 23 that did not meet their goal, all of which a dispatch-only rule accepts, and rejected 3 of 15 that did. Guided by these misses and a code audit, we fixed the agent; the gate then withheld 20 and rejected 1, at a median 30.6\,ms per decision, but on 12 held-out states it withheld only 2 of 5. We also design an extension to files, processes and native applications with accessibility-tree grounding, typed postconditions and deterministic permission tiers, and give an end-to-end evaluation protocol for local hardware.
\end{abstract}
