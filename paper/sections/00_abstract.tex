\begin{abstract}
Browser agents can report a task as finished when it is not, and many send every observation to a hosted model. Agentic Pilot is an open-source browser agent with local models that may report completion only when a rule-based predicate over the observed page holds, storing the inputs of each decision as evidence. We formalize this evidence-gated completion and measure it with false completion and false rejection rates. Inside the agent's live verification node, the gate withheld 20 of 23 unsatisfied design states (95\% interval 0.68--0.95) that a dispatch-only rule accepts, and rejected 1 of 15 satisfied ones; on 42 held-out states frozen before testing it withheld 9 of 22 (0.23--0.61; exact McNemar $p=0.004$) and none of the 5 unsatisfied extraction states, because its answer check depends on request wording. A decision costs a median of 27\,ms and no model call. Model traffic is restricted to the machine; in 70 agent episodes the agent process opened no non-loopback connection. Measurements show that memory retrieval has no relevance threshold and that recovery does not recognize a missing confirmation; a seeded simulation built on such measurements and stated assumptions suggests that the gate trades fewer false completions (19 against 28 per 100 synthetic scenarios) for more false rejections. No end-to-end run with a language model is reported; the harness for it is released.
\end{abstract}
