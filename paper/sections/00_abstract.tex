\begin{abstract}
Browser agents can report a task as finished when it is not, and many send every observation to a hosted model. Agentic Pilot is an open-source browser agent with local models that may report completion only when a rule-based predicate over the observed page holds, storing the inputs of each decision as evidence. We formalize this evidence-gated completion and its false completion and false rejection rates. \emph{Measured at component level}, in the agent's real verification node (called directly, with stubbed I/O), on 42 held-out states frozen before testing the gate withheld 9 of 22 unsatisfied states (0.23--0.61) and rejected 1 of 20 satisfied ones (exact McNemar on paired correct decisions $p=0.021$ against a dispatch-only rule), against 20 of 23 on the states its rules were fixed on, because its checks are keyed to request wording. A decision on the constructed states costs a median of 27\,ms and no model call. Privacy is meant in a narrow sense: by default the model client refuses non-loopback endpoints (an explicit override lifts this), and in 70 episodes with a scripted stand-in for the model server the agent's Python processes connected only to that stand-in on 127.0.0.1, which does not show where a real model server sends requests. Memory retrieval has no relevance threshold, and recovery does not recognize a missing confirmation. \emph{In a seeded simulation} built on these measurements and stated assumptions, the configuration with the gate ended in fewer false completions (19 against 28 of 100 synthetic scenarios, a direction fixed by construction) and its decision accuracy did not differ significantly from accepting every claim (52 against 46 of 74 synthetic claims, $p=0.15$); these values follow from the assumptions of a simulation model revised post hoc, after its first results were known, and are not measurements of the agent. \emph{No end-to-end evaluation with a language model was executed}; its harness is released.
\end{abstract}
