\begin{abstract}
LLM-based assistants that operate software for a user often send screenshots and page content to hosted models, often keep no memory across sessions, and can declare a task finished when it is not. We present Agentic Pilot, an open-source agent that runs its language and vision models locally through Ollama and drives Chromium through Playwright. The agent is a LangGraph state machine with separate observation, planning, execution, verification and recovery nodes, and it may report a task complete only when a completion predicate evaluated on the live page holds; evaluations are logged next to per-action before/after screenshots. Grounding uses Document Object Model (DOM) elements first and a local vision model as fallback; calls are routed to small models by role, CAPTCHAs halt the task, and high-risk intents need approval. We formalize the gate and define a false completion rate. On 38 constructed browser end states, the predicate withheld completion in 15 of the 23 states that did not meet their goal, all of which a dispatch-only rule accepts; inside the live verification node, where the planner's own reasoning can stand in for an answer, it withheld 13 to 14. It wrongly rejected 3 of 15 satisfied states, at a median 35.2\,ms per decision, and each miss points to a missing check. A code audit reports which mechanisms are live. We also design an extension to files, processes and native applications with accessibility-tree grounding, typed postconditions and deterministic permission tiers, and give an end-to-end evaluation protocol for local hardware.
\end{abstract}
