\section{Implementation}
\label{sec:impl}

The backend is Python (about 11{,}000 lines) on FastAPI, LangGraph, Playwright and Pydantic, with SQLite and a persistent local Chroma store; model calls use the Ollama HTTP API with JSON output and a fixable temperature and seed. The client is React in a Tauri shell. The code is public under the MIT license at \url{https://github.com/sudeshsudhii/Agentic-pilot-local}; this paper describes branch \texttt{ccr-4b8200f0-5i3k5m}, whose agent code (\texttt{backend/}) is unchanged since commit \texttt{bf0a8a5}; the experiment scripts, data and simulation are on the same branch. The repository's default branch has diverged (it defaults to a hosted model and adds desktop automation) and is not the version evaluated here; the evaluated version of the paper's artifacts is the head of that branch at submission, to be fixed by a release tag.

\paragraph{Fixes} The audit and the gate study led to fixes. At commit \texttt{2361d50}, the extraction handler formatted every answer as facts about one university campus and substituted fixed text when a page had too few matching lines; it now keeps only page lines that share terms with the goal. The verification node accepted the reasoning of any action as an answer and let a \texttt{complete} action mark a pending step done; both are fixed, and the $Q$, sign-in and ``not found'' checks, exact matching and goal-term overlap were added. Bot-check detection no longer fires on titles that contain ``robot'' or on hidden frames. The vision-fallback strategy, memory retrieval and the verification switch were inert and now take effect; routing keywords match whole words. The repository's earlier ``certification'' figures counted a task as passed when it ended as completed and a screenshot existed, and we use none of them.

\paragraph{Locality enforcement} The model client refuses any endpoint whose host is not a loopback address (127.0.0.0/8, \texttt{::1}) or a \texttt{localhost} name (accepted without DNS resolution), before connecting, unless the user sets \texttt{PILOT\_ALLOW\_REMOTE\_MODEL=true}; LAN, link-local and unspecified addresses count as remote. The check applies to the configured address, not to the model name or proxy settings. Chroma stores are created with telemetry disabled, and the privacy audit log classifies destinations by parsed host instead of by substring. For experiments we added switches that replace $\Phi$ by no check or by a self-check of the planner model, remove single conjuncts, or pin one recovery strategy, and the gateway records the token counts that Ollama reports.
