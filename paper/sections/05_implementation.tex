\section{Implementation}
\label{sec:impl}

The backend is Python (about 11{,}000 lines) on FastAPI, LangGraph, Playwright and Pydantic, with SQLite and a persistent local Chroma store; model calls use the Ollama HTTP API with JSON output and a fixable temperature and seed. The client is React in a Tauri shell. The code is public under the MIT license at \url{https://github.com/sudeshsudhii/Agentic-pilot-local}; this paper describes commit \texttt{bf0a8a5}.

\paragraph{Component audit} Agent documentation tends to run ahead of the code, so we traced each component to the code path that executes it and to the tests and experiments that exercise it (Table~\ref{tab:status}). Claims in this paper are restricted to rows with evidence in the last column; the other rows are implemented but unevaluated, or designs.

\paragraph{Fixes} The audit and the gate study led to fixes. At commit \texttt{2361d50}, the extraction handler formatted every answer as facts about one university campus and substituted fixed text when a page had too few matching lines; it now keeps only page lines that share terms with the goal. The verification node accepted the reasoning of any action as an answer and let a \texttt{complete} action mark a pending step done; both are fixed, and the $Q$, sign-in and ``not found'' checks, exact matching and goal-term overlap were added. Bot-check detection no longer fires on titles that contain ``robot'' or on hidden frames. The vision-fallback strategy, memory retrieval and the verification switch were inert and now take effect; routing keywords match whole words. The repository's earlier ``certification'' figures counted a task as passed when it ended as completed and a screenshot existed, and we use none of them.

\paragraph{Locality enforcement} The model client now refuses any endpoint whose host is not a loopback name or address, before connecting, unless the user sets an explicit override; LAN addresses count as remote. Chroma stores are created with telemetry disabled, and the privacy audit log classifies destinations by parsed host instead of by substring. For experiments we added switches that replace $\Phi$ by no check or by a self-check of the planner model, remove single conjuncts, or pin one recovery strategy, and the gateway records the token counts that Ollama reports.
