\section{Implementation}
\label{sec:impl}

The backend is Python (10{,}867 lines, 1{,}679 of them in the graph nodes) on FastAPI, LangGraph, Playwright and Pydantic, with SQLite for tasks and events and a persistent local Chroma store. Model calls use the Ollama HTTP API with JSON output, and sampling temperature and seed can be fixed for experiments. The client is React in a Tauri shell, whose native commands only report the status of the backend and of Ollama. The code is public at \url{https://github.com/sudeshsudhii/Agentic-pilot-local}; this paper describes commit \texttt{eb3803e}. \todo{AUTHOR: confirm license; archive the evaluated version (tagged release with DOI).}

\paragraph{Capability audit} Because agent documentation tends to run ahead of the code, we traced each capability to the code path that executes it and to the tests and experiments that exercise it (Table~\ref{tab:status}). The browser backend and the shared loop are implemented, integrated and tested; the completion predicate, bot-check halting and browser control are additionally evaluated at component level. Of the computer backend, only a desktop input prototype, a file helper and a file predicate exist, none integrated, and nothing is evaluated.

\paragraph{Fixes} The audit and the gate study of Section~\ref{sec:results} led to fixes in the agent. At commit \texttt{2361d50}, the extraction handler formatted every answer as facts about one university campus and substituted fixed text when a page had too few matching lines; it now keeps only page lines that share terms with the goal and invents nothing. The completion gate accepted the reasoning of any action as an answer and let a \texttt{complete} action mark a pending step done; both are fixed, and the $Q$, sign-in and ``not found'' checks, exact matching and goal-term overlap were added. Bot-check detection no longer fires on titles that merely contain ``robot'' or on hidden frames. The vision-fallback strategy, memory retrieval and the verification switch were inert and now take effect; routing keywords match whole words, and model stickiness no longer carries across tasks. The evaluation command ran scripts absent from the repository and its runner imported a missing function; both now run six ablation presets. The repository's earlier ``certification'' figures counted a task as passed when it ended as completed and any screenshot and a trace file existed, and we use none of them. The test suite gained 19 regression tests.
