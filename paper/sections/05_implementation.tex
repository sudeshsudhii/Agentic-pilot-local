\section{Implementation}
\label{sec:impl}

The backend is Python (about 11{,}000 lines) on FastAPI, LangGraph, Playwright and Pydantic, with SQLite and a persistent local Chroma store; model calls use the Ollama HTTP API with JSON output and a fixable temperature and seed. The client is React in a Tauri shell. The code is public under the MIT license at \url{https://github.com/sudeshsudhii/Agentic-pilot-local}; the evaluated agent code is commit \texttt{bf0a8a5} on branch \texttt{ccr-4b8200f0-5i3k5m}, which also holds all scripts and data (the default branch has diverged and is not the evaluated version).

\paragraph{Component audit} We traced each component to the code path that executes it and to the tests and experiments that exercise it (Supplement, Table~\ref{tab:status}): the gate, browser control, locality enforcement and the oracle are implemented and evaluated at component level; recovery and memory are implemented and studied by measurement and simulation; the planner in the full loop, vision fallback and the self-verification mode are implemented but unevaluated; the desktop backend, action gate, enhanced validation, evidence-guided recovery and memory filter are proposed. Claims are restricted to evaluated components.


\paragraph{Fixes} The audit and the gate study led to fixes. The extraction handler returned fixed text about one campus (\texttt{2361d50}); the verification node took any action's reasoning as an answer and let a \texttt{complete} action mark a pending step done; bot-check detection fired on titles containing ``robot''; vision fallback, memory retrieval and the verification switch were inert. All are fixed, and the $Q$, sign-in and ``not found'' checks were added. The repository's earlier ``certification'' figures counted any completed task with a screenshot as passed; we use none of them.

\paragraph{Locality enforcement} The model client refuses any endpoint whose host is not a loopback address (127.0.0.0/8, \texttt{::1}) or a \texttt{localhost} name (accepted without DNS resolution), before connecting, unless the user sets \texttt{PILOT\_ALLOW\_REMOTE\_MODEL=true}; LAN, link-local and unspecified addresses count as remote. The check applies to the configured address, not to the model name or proxy settings. Chroma telemetry is disabled. Experiment switches replace $\Phi$ by no check or a model self-check, remove single conjuncts, or pin one recovery strategy.
