\section{Safety, Privacy and Autonomy}
\label{sec:safety}

\paragraph{Threat model} The user and the host are trusted; content the agent reads is not. We consider injected instructions~\cite{greshake2023indirect}, high-impact actions without consent, exposure of credentials and sensitive screenshots, and disclosure of user data to a model provider; a compromised host, browser or model is out of scope.

\paragraph{Privacy property} We call the system privacy-preserving in this sense: \emph{by default the model client sends prompts and screenshots only to a model server on the loopback interface, and the code writes task records, memory and evidence only to local files.} Evidence for it is the endpoint refusal, disabled Chroma telemetry and the egress test of Section~\ref{sec:res-privacy}; local file storage is established by code inspection. It does not cover what the loopback model server does with a request (Ollama cloud models or a tunnel forward it off the machine); data entered on websites or sent to the user-invoked search fallback; one-time downloads of model weights and embeddings; proxy environment variables, which the HTTP client honours; the monitoring UI's web fonts; and unencrypted local storage. It is not a privacy guarantee.




\paragraph{Autonomy and what the implementation provides} The agent acts only in the browser and exposes no file, process or command action. A task classified as posting, e-mailing, purchasing, deleting or transferring, or as high risk, waits for the user's approval; bot checks stop the task for the user; a sanitizer replaces 17 injection patterns in element text; the service listens only on loopback, and successful model calls are logged with destination and payload sizes.

\paragraph{What it does not provide} The sanitizer is a fixed denylist; the approval decision is made once per task by a small model; the local API has no authentication or Origin check; typed text and screenshots are stored unredacted in clear. We make no security claim; the threat table and details are in the Supplement (Section~\ref{sec:sec-full}).
